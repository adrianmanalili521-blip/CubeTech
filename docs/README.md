## Project Summary

CubeTech is a full-stack shopping application with:

- a React and TypeScript storefront for browsing products, managing a cart, and checking out
- an Express and SQLite backend for authentication, orders, and admin management
- an admin experience for products, categories, orders, and customer data

## Quick Start

1. Install frontend dependencies in the front-end folder.
2. Install backend dependencies in the back-end folder.
3. Start the backend server.
4. Start the Vite development server.
5. Open the app in the browser at http://localhost:5173.

Default admin credentials:

- Email: admin
- Password: 123
