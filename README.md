# CubeTech

CubeTech is a **full-stack electronics e-commerce application** built with **React, TypeScript, Express, and SQLite**. It provides a modern shopping experience for customers while giving administrators complete control over products, categories, customers, and orders.

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

### Backend
- Express.js
- SQLite
- Node.js

---

## Project Structure

```
CubeTech/
│
├── front-end/     # React + TypeScript application
├── back-end/      # Express + SQLite REST API
└── docs/          # Documentation
```

---

## Features

### Customer
- Browse products
- View product details
- Category-based product filtering
- Shopping cart
- Checkout
- Order history

### Admin
- Dashboard overview
- Product management
- Category management
- Order management
- Customer management

# Getting Started

## 1. Install Dependencies

Frontend

```bash
cd front-end
npm install
```

Backend

```bash
cd ../back-end
npm install
```

---

## 2. Start the Backend

```bash
cd back-end
npm run dev
```

---

## 3. Start the Frontend

```bash
cd front-end
npm run dev
```

---

## Local Development

| Service | URL |
|---------|-----|
| Frontend | http://localhost:5173 |
| Backend API | http://localhost:5000 |
